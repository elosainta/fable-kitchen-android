# Fable Kitchen — Android test builds

Early test builds of the Fable Kitchen phone app. **APK files only** — no source code lives here.

Everything in these builds runs on a **dummy database on the phone**: the figures are made-up sample data, nothing is sent to or read from the real kitchen system, and sign-in accepts any email and password.

## Install

1. Open the latest release on the phone and download the `.apk`.
2. Open it, allow installing from that source when Android asks, then **Install**.

Needs Android 8.0 or newer.

## Updates

The app checks this repo's latest release when you sign in. When a newer version is out, the home screen shows **Version x.y is ready** with an **Update** button: it downloads the new APK and opens Android's installer. The first time, Android asks you to allow installs from Fable Kitchen.
